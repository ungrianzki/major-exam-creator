Question bank file format

A CSV, TSV or Excel file with these column headers (order and capitalization don't matter). Option E may be blank for 4-option items.

Question | Option A | Option B | Option C | Option D | Option E | CORRECT ANSWER | DIFFICULTY | BLOOMS | CONTENT | OBJECTIVES

CORRECT ANSWER is the letter (A–E). BLOOMS is Remembering / Understanding / Applying / Analyzing / Evaluating / Creating (any casing). CONTENT should match a content name from Step 2. OBJECTIVES should match one of the objectives you typed for that content (same wording, or close to it) — the app spreads the chosen questions across the objectives. DIFFICULTY is kept for the answer key.
